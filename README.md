# Bank Management System (C++)

This project is a console-based Bank Management Application developed in C++ using Object-Oriented Programming concepts and File Handling.

## Features
- Create Account
- Deposit Money
- Withdraw Money
- Balance Inquiry
- File Handling for Data Storage
- Secure Customer Record Management

## Technologies Used
- C++
- OOP Concepts
- File Handling

## Concepts Covered
- Classes & Objects
- Encapsulation
- Functions
- Conditional Statements
- Loops
- File Operations

## How to Run
1. Compile the program:
   g++ main.cpp -o bank

2. Run:
   ./bank
